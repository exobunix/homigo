# Assets Folder

This folder contains app assets like icons and splash screens.

For a complete setup, you'll need:
- icon.png (1024x1024)
- splash.png (1284x2778 for iOS, 1080x1920 for Android)
- adaptive-icon.png (1024x1024)
- favicon.png (48x48)

You can generate these using the Expo CLI:
```bash
npx expo install expo-splash-screen
npx expo install expo-app-icon
```

Or use online tools like:
- https://www.appicon.co/
- https://appsplashscreen.com/
